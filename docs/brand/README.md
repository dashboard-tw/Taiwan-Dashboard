# Logo

黑底白色的臺灣島，版面參考臺北城市儀表板的 Logo。

臺灣的外形來自 SVG Repo 的 [Taiwan Taiwan](https://www.svgrepo.com/svg/308354)，CC0 授權。網站頂部列的圖示 `Taiwan-Dashboard-FE/src/components/layout/TaiwanLogo.vue` 用的是同一個外形。

## 檔案

| 檔案 | 大小 | 用途 |
|---|---|---|
| `Taiwan-Dashboard-FE/public/logo.svg` | 向量 | 原始檔，其他尺寸都從這裡產生 |
| `Taiwan-Dashboard-FE/public/logo.png` | 512 × 512 | 一般使用 |
| `Taiwan-Dashboard-FE/public/favicon.svg` | 向量 | 瀏覽器分頁圖示 |
| `Taiwan-Dashboard-FE/public/apple-touch-icon.png` | 180 × 180 | iPhone 主畫面圖示 |
| `docs/brand/logo-square-1024.png` | 1024 × 1024 | GitHub 組織頭像與 OAuth App |
| `docs/brand/logo-square-120.png` | 120 × 120 | Google OAuth 同意畫面 |
| `docs/brand/logo-rounded-1024.png` | 1024 × 1024 | 簡報、社群 |
| `docs/brand/social-preview.jpg` | 2560 × 1280 | GitHub 倉庫的 Social preview，用網站實際畫面製作 |

## 規格

512 × 512 的方格，圓角半徑 80。臺灣島高 410，置中。只用黑 `#000000` 和白 `#ffffff`。

修改時先改 `logo.svg`，再重新產生各尺寸。
